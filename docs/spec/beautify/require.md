# Quartz 博客美化需求文档补全方案

## 摘要
- 需求以仓库现状为锚点，明确复用 `quartz.config.ts`、`quartz.layout.ts`、`content/index.md` 的现有能力，不把方案写成脱离 Quartz 的纯视觉稿。
- 默认采用以下已确认取舍：真实目录迁移、旧 URL 不兼容、首页精选文章走站点总配置、控件按首页/列表页/文章页分层收敛、视觉为“风格借鉴”而非逐像素复刻。

## 关键补充
- 将“信息架构重组”改写为明确的新目录与页面层级：
  - 首页独立保留。
  - 知识库下为 `人工智能 / 工具使用 / 专业学习`，对应迁移原 `00人工智能 / 01工具使用 / 02专业学习`。
  - 文章库下为 `归档文章 / 技术文章`，对应迁移原 `归档文章 / 技术文章`。
- 明确需求中的配置入口：
  - 站点总配置中新增顶部导航配置、首页 Hero 配置、3 篇精选文章 slug 配置。
  - 精选文章来源于现有内容，不新增后台系统或数据库。
- 明确页面行为分层：
  - 首页仅保留固定顶部导航与 Hero，隐藏搜索、目录树、图谱、最近更新等工具控件。
  - 列表页保留导航与必要列表信息，弱化工具感。
  - 文章页保留导航和主要阅读辅助能力，但整体视觉需与首页风格统一。
- 把“与示例网站高度一致”改写为可执行视觉约束：
  - 浅底色、点阵/网格背景、强识别度大标题、细边框导航、描边按钮、少量橙色强调。
  - 保持复古科技感与极简品牌感，不要求逐像素复刻。
  - 需兼顾 Quartz 的阅读场景和移动端适配。
- 补齐迁移约束：
  - 因不兼容旧 URL，需求中需明确同步更新导航入口、首页链接和迁移后引用关系。
  - 现有内容规模可作为背景写入：知识类约 157 篇，文章类约 9 篇。
  - Hero 文案、个人标签语、个人简介、精选文章名单、头像最终选用统一标记为 `【待确认】`。

## 验收与场景
- 顶部导航在首页、文章库、知识库、文章详情页全站固定可见，且当前页面有高亮态。
- 首页具备头像、标签语、简介、3 篇精选文章入口，并满足极简展示要求。
- 知识库与文章库都能进入对应子分类，迁移后分类内容与原目录一一对应。
- 站点总配置修改后，可替换导航文案、Hero 信息和 3 篇精选文章，无需改组件源码。
- 桌面端与移动端都能正常浏览，首页与内容页的视觉层次一致但功能密度不同。
