优化博客网站风格与结构，具体实施要求如下：

1. 站点信息架构重组
   - 重构为三大核心板块：`首页`、`知识库`、`文章库`
   - 各板块功能定位：
     - `首页`：强化品牌形象展示，突出个人品牌识别度
     - `知识库`：承载体系化、结构化学习内容，构建知识体系
     - `文章库`：展示单篇独立的表达型内容，体现思想观点

2. 视觉风格与设计规范
   - 全站视觉风格需与示例网站保持高度一致，包括但不限于背景样式、组件设计、色彩方案和排版风格
   - 优先复用Quartz现有功能模块与组件，仅在必要时开发最小量的自定义组件和样式，确保系统轻量且易于维护

3. 导航系统优化
   - 实现固定顶部导航栏，全站统一显示，包含三个核心导航项：`首页 / 知识库 / 文章库`
   - 导航交互需符合现代网页设计标准，包含悬停效果、当前页面高亮指示

4. 内容组织与分类体系
   - `知识库`板块下聚合三个子分类：`人工智能 / 工具使用 / 专业学习`
   - `文章库`板块下聚合两个子分类：`归档文章 / 技术文章`

5. 首页设计与功能优化
   - 首屏区域采用个人介绍Hero设计，包含以下元素：
     - 个人头像展示（需提供清晰的头像资源）
     - 一句精准的个人定位/标签语
     - 一段简洁的个人简介文本
     - 3篇指定文章的链接入口（需支持后台配置指定文章）
   - 首页需隐藏所有非必要控件元素，减少工具感，营造简洁、专注的阅读体验
