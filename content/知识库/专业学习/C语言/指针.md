## 什么是指针？

#import/pf 所有实际[数据类型](数据类型.md)，不管是整型、浮点型、字符型，还是其他的[数据类型](数据类型.md)，**对应指针的值的类型都是一样的**，都是一个代表内存地址的长的十六进制数。

不同[数据类型](数据类型.md)的指针之间唯一的不同是，指针所指向的变量或常量的[数据类型](数据类型.md)不同。

## C 中的 NULL 指针

在变量声明的时候，如果没有确切的地址可以赋值，**为指针变量赋一个 NULL 值是一个良好的**[编程习惯](其他/编程习惯.md)。赋为 NULL 值的指针被称为**空**指针。

## 指针[数组](数组.md)

指针[数组](数组.md)存储了一组指针，每个指针可以指向不同的数据对象。

示例：在这里，把 **ptr** 声明为一个[数组](数组.md)，由 MAX 个整数指针组成。因此，ptr 中的每个元素，都是一个指向 int 值的指针。下面的实例用到了三个整数，它们将存储在一个指针[数组](数组.md)中，如下所示：

```c
#include <stdio.h>
 
const int MAX = 3;
 
int main ()
{
   int  var[] = {10, 100, 200};
   int i, *ptr[MAX];
 
   for ( i = 0; i < MAX; i++)
   {
      ptr[i] = &var[i]; /* 赋值为整数的地址 */
   }
   for ( i = 0; i < MAX; i++)
   {
      printf("Value of var[%d] = %d\n", i, *ptr[i] );
   }
   return 0;
}
```

您也可以用一个**指向字符的指针[数组](数组.md)来存储一个[字符串](字符串.md)列表**，如下：

```c
#include <stdio.h>
 
const int MAX = 4;
 
int main ()
{
   const char *names[] = {
                   "Zara Ali",
                   "Hina Ali",
                   "Nuha Ali",
                   "Sara Ali",
   };
   int i = 0;
 
   for ( i = 0; i < MAX; i++)
   {
      printf("Value of names[%d] = %s\n", i, names[i] );
   }
   return 0;
}
```

指针[数组](数组.md)在C中非常有用，特别是在处理具有不定数量元素的数据结构时，如动态分配的[字符串](字符串.md)[数组](数组.md)或动态创建的[结构体](结构体.md)数组。

## [函数](函数.md)指针

[函数](函数.md)指针是指向[函数](函数.md)的指针变量。

通常我们说的指针变量是指向一个整型、字符型或[数组](数组.md)等变量，而[函数](函数.md)指针是指向[函数](函数.md)。

[函数](函数.md)指针可以像一般[函数](函数.md)一样，用于调用[函数](函数.md)、传递参数。

[函数](函数.md)指针类型的声明：

```c
typedef int (*fun_ptr)(int,int); // 声明一个指向同样参数、返回值的函数指针类型
```

实例：以下实例声明了[函数](函数.md)指针变量 p，指向[函数](函数.md) max：

```c
#include <stdio.h>
 
int max(int x, int y)
{
    return x > y ? x : y;
}
 
int main(void)
{
    /* p 是函数指针 */
    int (* p)(int, int) = & max; // &可以省略
    int a, b, c, d;
 
    printf("请输入三个数字:");
    scanf("%d %d %d", & a, & b, & c);
 
    /* 与直接调用函数等价，d = max(max(a, b), c) */
    d = p(p(a, b), c); 
 
    printf("最大的数字是: %d\n", d);
 
    return 0;
}
```

## 回调[函数](函数.md)

### [函数](函数.md)指针作为某个[函数](函数.md)的参数

[函数](函数.md)指针变量可以作为某个[函数](函数.md)的参数来使用的，回调[函数](函数.md)就是一个通过[函数](函数.md)指针调用的[函数](函数.md)。

简单讲：回调[函数](函数.md)是由别人的[函数](函数.md)执行时调用你实现的[函数](函数.md)。

实例中 **populate_array()** [函数](函数.md)定义了三个参数，其中第三个参数是[函数](函数.md)的指针，通过该[函数](函数.md)来设置[数组](数组.md)的值。

实例中我们定义了回调[函数](函数.md) **getNextRandomValue()**，它返回一个随机值，它作为一个[函数](函数.md)指针传递给 **populate_array()** [函数](函数.md)。

**populate_array()** 将调用 **10** 次回调[函数](函数.md)，并将回调[函数](函数.md)的返回值赋值给[数组](数组.md)。

```c
#include <stdlib.h>  
#include <stdio.h>
 
void populate_array(int *array, size_t arraySize, int (*getNextValue)(void))
{
    for (size_t i=0; i<arraySize; i++)
        array[i] = getNextValue();
}
 
// 获取随机值
int getNextRandomValue(void)
{
    return rand();
}
 
int main(void)
{
    int myarray[10];
    /* getNextRandomValue 不能加括号，否则无法编译，因为加上括号之后相当于传入此参数时传入了 int , 而不是函数指针*/
    populate_array(myarray, 10, getNextRandomValue);
    for(int i = 0; i < 10; i++) {
        printf("%d ", myarray[i]);
    }
    printf("\n");
    return 0;
}
```
